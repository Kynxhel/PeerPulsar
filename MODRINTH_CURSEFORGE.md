# 🌐 Fabric P2P World

**Host and join Minecraft 26.3 worlds peer-to-peer — directly from the Pause Menu, with zero server setup and zero monthly cost.**

---

### ✨ Why Fabric P2P World?
- **No Port Forwarding Headaches:** Automatically tests your network (UPnP, CGNAT, Cone vs. Symmetric NAT, and Relay latency) and highlights the fastest working mode with **`(Recommended)`**.
- **Works Even Behind CGNAT:**
  - **Direct P2P (UPnP):** `0 ms` overhead when Open NAT + UPnP is available.
  - **UDP Hole Punch:** Direct peer-to-peer UDP traversal (`0 ms` relay latency) for Cone CGNAT connections.
  - **Tunnel Relay:** Built-in fallback relay for Symmetric NAT and strict networks.
  - **Local LAN:** Instant same-network hosting.
- **Sleek Neon UI & Live Ping:** Built-in server status ping (latency ms, player count, MOTD) before you join, plus smart clipboard parsing (paste an entire Discord invite and the room code is extracted automatically!).
- **Optional Shared Cloud Worlds (Toggleable):** Enable `☁ Shared Worlds` to sync a world via Google Drive or a local synced folder (OneDrive / Dropbox / Syncthing) with automatic host rotation — whoever launches first becomes Host, and friends join with 1 click!
- **Configurable LAN Options:** Easily toggle Game Mode, Cheats, Port (25565 or Random), and Offline LAN Auth mode for local testing.

---

### 📋 Requirements
- **Minecraft:** `26.3`
- **Mod Loader:** Fabric Loader `>= 0.19.5`
- **Dependencies:** [Fabric API](https://modrinth.com/mod/fabric-api) (for `26.3`)
- **Java:** Java 21+
