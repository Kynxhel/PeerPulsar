# Changelog

> **Project History:** Originally created as *FabricP2PMod*, temporarily rebranded to *Atarca* in v3.0.0 (when Cloud Sync / Google OAuth was removed), and renamed to **PeerPulsar** in v3.1.0.

## v4.0.0+26.3
- **3-Engine Adaptive UDP P2P Transport (`RUDP` / `KCP` / `QUIC`) + Auto Selection:** Upgraded UDP Hole Punching (`UdpHolePunchService`) with a connect-time 4-packet UDP probe and automatic per-player engine selection (`TransportSwitchAdvisor`): **RUDP** (minimal framing/CPU for `<55 ms`, `0%` loss, `<15 ms` jitter links), **KCP** (`10 ms` tick, 64-bit SACK, fast-resend after 2 skips, 256-packet window for jittery/PvP/mild-loss links), and **QUIC (`tech.kwik:kwik:0.12.2`)** (TLS 1.3 encrypted transport over a demultiplexed NAT-punched socket with ephemeral P-256 certs pinned via AES-256-GCM signaling for high ping/loss/mobile links, plus automatic KCP fallback if blocked).
- **In-Game Bottom-Right Switch Popup & Auto-Reconnect:** Added live RTT/jitter/loss monitoring and a non-blocking bottom-right Neon popup (`TransportRecommendationOverlay` + clickable chat prompt) with hysteresis and 5-minute cooldown whenever sustained network shifts suggest switching engines. Clicking **Switch** disconnects cleanly and automatically reconnects using the saved room code + `#KEY`. Added manual engine selection (`Auto` / `RUDP` / `KCP` / `QUIC`) and **Auto Switch Hints** toggle to **⚙ Advanced → Network Services → UDP Engine**.
- **Join Approval Default ON, Kick Revocation & Per-Guest OP Toggle:** Enabled **Join Approval** by default (`PeerPulsarConfig`), automatically revoked saved `Always`-approval entries when kicking a player (`ApprovedPlayerStore.removeByNameOrUuid`) with host chat notification on pre-approved joins, added click sound feedback on approval buttons (`JoinApprovalOverlay`), added an **OP** toggle button next to **Kick** for each connected guest on `P2PHostScreen`, and fixed `IntegratedServerMixin.getProfilePermissions` so individual guest OP permissions override global `guestCommandAccess=false` cleanly.
- **MC 26.3 Mouse Input & `players/data` Compatibility Fixes:** Replaced hardcoded button `0` checks with `InputConstants.MOUSE_BUTTON_LEFT` across `P2PAdvancedScreen`, `P2PHostScreen`, and `JoinApprovalOverlay`; updated `PlayerDataMigrator` and `P2PAdvancedScreen` to resolve MC 26.3's `players/data`, `players/advancements`, and `players/stats` paths; and overhauled playerdata **Transfer** to use Source → Target order, exclude the host UUID, and safely flush/kick online recipients before copying.

## v3.2.4+26.3
- **Host Screen Initial Network Test UX:** Added an attention-pulsing halo and shimmer (`NeonButton.setAttentionPulse`) plus an animated bouncing `»` pointer next to the **Test** button on `P2PHostScreen` whenever network diagnostics have not been run yet (`IDLE`), styled untested internet connection mode cards (`Direct P2P`, `UDP Punch`, `Tunnel Relay`) with calm amber indicators instead of red error styling, and updated the idle/untested labels (`en_us.json` / `tr_tr.json`) to clearly prompt clicking **Test**.

## v3.2.3+26.3
- **Log Privacy Redaction:** Removed public IP addresses, router WAN IPs, peer IP addresses, signaling topic IDs, and room codes/`#KEY` secrets from `latest.log` and host chat log output so sharing game logs for troubleshooting never leaks sensitive network or room credentials.
- **Independent Host & Join Consent Flags:** Separated host-side Network Diagnostics consent (`networkTestConsent`) from join-side UDP P2P consent (`udpJoinConsent`), and ensured trusting a one-off custom signaling invite no longer auto-grants host diagnostics or default UDP consent.
- **Relay & STUN SSRF Hardening:** Extended public-only validation and DNS-rebinding pinned resolution (`resolvePinnedPublicAddress`) to custom Tunnel Relay and STUN `host:port` endpoints in `NetworkEndpoints`, `TunnelRelayService`, `UdpHolePunchService`, and `P2PAdvancedScreen`, blocking loopback, link-local, RFC1918, CGNAT, and ULA targets.
- **Identity Key & Out-of-Instance Backup Hardening:** Applied owner-only file permissions (`0600` on POSIX / owner-only ACL fallback) to `identity.json`, backups, and exported keys, and moved default identity backup exports outside `.minecraft` (`~/.peerpulsar/peerpulsar-identity-backup.json`, while retaining legacy `.minecraft` import fallback) so exporting modpacks never bundles private keys.

## v3.2.2+26.3
- **End-to-End Encrypted Offline LAN Auth & Zero Session Token Access:** Enabled Minecraft's native RSA + AES-CFB8 transport encryption (`shouldAuthenticate = false`) in Offline LAN Auth, channel-bound via SHA-256 host key hash into the `#KEY` HMAC and Ed25519 signature to protect gameplay traffic against MITM and eavesdropping even over `bore.pub` or UDP Hole Punch, and removed hybrid Mojang session checks so PeerPulsar never reads `User.getAccessToken()` or contacts Mojang session servers on behalf of clients.
- **Named First-Use Consent & Storefront Disclosures:** Updated host diagnostics, UDP join consent, custom signaling warning, Offline LAN Auth warning, and HTTPS error strings (`en_us.json` / `tr_tr.json`) plus `README.md`, `MODRINTH_CURSEFORGE.md`, and `PRIVACY.md` to explicitly name `bore.pub`, `ntfy.sh`, and STUN/IP echo servers as optional free third-party defaults changeable in **⚙ Advanced**.
- **SSRF & UPnP Hardening:** Disabled HTTP redirects, enforced DNS-rebinding pinned public HTTPS checks on custom endpoints, and restricted UPnP SSDP/SOAP requests to the responding local gateway IP.
- **Icon Optimization:** Compressed `assets/peerpulsar/icon.png` (`512x512`) under 256 KiB (`~49 KB`) while preserving crisp quality and alpha transparency.
