# Changelog

## v3.0.0+26.3
- **Rebranded to Atarca:** Renamed the mod, ID (`atarca`), assets, UI titles, chat notifications, and release artifacts (`atarca-26.3-*.jar`) to **Atarca**.
- **Removed Cloud World Sync & Google OAuth:** Completely removed Shared Cloud Worlds, Google Sign-In, Google Drive sync, and OIDC identity locking. Google Drive's `drive.file` scope does not permit invited players to read files created by another user inside shared folders, while the full `drive` scope enforces a 100-user cap on unverified apps and requires a paid annual CASA audit. Atarca now focuses 100% on fast, unlimited, zero-account P2P world hosting (Direct UPnP, UDP Hole Punching, Tunnel Relay, and Local LAN).

## v2.1.14+26.3
- **Hotfix MC 26.3 `MinecraftMixin` Crash:** Replaced the removed `Minecraft.screen` `@Shadow` field with `Minecraft.gui.screen()` for Minecraft 26.3 compatibility.

- **Sync-Before-Quit Screen (`ExitSyncScreen`):** Intercepted **Esc → Save and Quit to Title** via `MinecraftMixin` whenever playing a Shared Cloud World with **Auto-Sync on Exit** enabled — saves and incrementally uploads changed files to Google Drive / Sync Folder first with a live progress screen (plus Retry / Skip options if offline), then automatically exits to the Title Screen and releases the session lock without duplicate uploads.

## v2.0.0+26.3
- **Minecraft 26.3 Native Support:** Built natively for Minecraft 26.3 (unobfuscated) with Fabric Loader `>=0.19.5` and Fabric API `0.165.2+26.3`.
- **Neon Control Center UI:** Custom glassmorphism host, join, and shared worlds screens with animated particle background, live signal bars, and toast notifications.
- **Automatic Network & NAT Diagnostics:** Dual-STUN Cone/Symmetric NAT detection, CGNAT (`100.64.0.0/10`) detection, UPnP port-mapping self-test, and tunnel latency check.
- **Right-Side Connection Mode Selector:** 4 selectable modes (`Direct P2P`, `UDP Punch`, `Tunnel Relay`, `Local LAN`) with green/red status dots and automatic `(Recommended)` tagging.
- **UDP Hole Punching Engine:** Direct peer-to-peer Reliable Ordered UDP (RUDP) traversal through Cone CGNAT.
- **Automatic TCP Tunnel Relay:** Built-in `bore.pub` fallback for Symmetric NAT and strict firewalls.
- **Toggleable Shared Cloud Worlds:** Optional rotating-host world sync with Google Drive Sign-In (OAuth 2.0 + PKCE) and local synced folder support.
- **Smart Room Codes & Live Ping:** Auto-extracts room codes from pasted Discord invites and displays live latency/player telemetry.
